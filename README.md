# App de Orçamento

App full stack para freelancers criarem, enviarem e acompanharem orçamentos.

## Stack

- Front-end: React + TypeScript + Vite
- API: Node + TypeScript + Express
- Banco: PostgreSQL (próximas etapas)

## Como rodar

```bash
npm install
cp apps/api/.env.example apps/api/.env
npm run dev
```

- Web: http://localhost:5173
- API: http://localhost:3333/health
